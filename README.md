# html_css_homework

Учебный репозиторий по курсу Sky.pro «Инструменты тестирования веб-приложений».

Содержит три пары HTML/CSS-файлов из домашнего задания «Работа с версткой HTML и CSS»:
верстка, в которой были найдены и исправлены ошибки, из-за которых смысл текста не
соответствовал его внешнему виду (несовпадающие CSS-классы, инлайн-стили, перепутанные
свойства CSS и т.д.).

## Файлы

- `task1.html` + `styles1.css` — задание №1
- `task2.html` + `styles2.css` — задание №2
- `task3.html` + `styles3.css` — задание №3 (усложнённое)

Репозиторий также используется для практики работы с ветками и pull request'ами
в рамках домашнего задания «Системы контроля версий (Git, GitHub)».
